# 🌍 **MULTIPLE LANGUAGE TRANSLATOR**

A **Streamlit-based Multi Language Translator Application** that allows users to translate text into multiple languages, listen to translated output using **Text-to-Speech**, and download the generated audio — all within a modern and interactive UI.

## 🚀 **FEATURES**

- 🌐 Translate text into **multiple languages**
- 🔊 Listen to translated text using **Text-to-Speech**
- ⬇️ Download translated audio in **MP3 format**
- 🎨 Clean and modern UI with background image
- 📂 Multi-page navigation (Home, Translator, About)
- ⚡ Fast & lightweight Streamlit app

---

## 🛠️ **TECH STACK**

- **Streamlit** – Frontend & UI
- **mtranslate** – Text translation
- **gTTS (Google Text-to-Speech)** – Audio generation
- **pandas** – Language CSV handling
- **Python** – Core programming language

**🧭 HOW TO USE**

Open the application in your browser

Select Translator from the sidebar

Enter the text you want to translate

Choose the target language

View translated text and listen to audio

Download the MP3 file if required
